# System Cheatsheet

## Bootstrapping
- **Build VM**: `make build-vm`
- **Apply Ansible Locally**: `make apply`
- **Test with Molecule**: `make test`
- **Export VM**: `make export-vm`

## Package Management
- **Install AUR Package**: `yay -S <package>`
- **Update System**: `yay -Syu`
- **Clean Cache**: `yay -Sc`

## Important Aliases
- `sysman`: Opens the system manual (via fzf or glow)
