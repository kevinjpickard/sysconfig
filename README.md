# System Configuration (Packer + Ansible)

This branch contains a modernized Packer and Ansible workflow to automate a clean install of Arch Linux with KDE Plasma.

## Prerequisites

- [Packer](https://www.packer.io/downloads)
- [Ansible](https://docs.ansible.com/ansible/latest/installation_guide/intro_installation.html)
- A hypervisor like VirtualBox, QEMU, VMware, or Parallels.

## Building the Image

The legacy JSON template has been converted to HCL2 (`archlinux.pkr.hcl`).

To build a VirtualBox image with the KDE setup:

```bash
packer init archlinux.pkr.hcl
packer build -only virtualbox-iso.autogenerated_3 archlinux.pkr.hcl
```

To build for QEMU:

```bash
packer build -only qemu.autogenerated_2 archlinux.pkr.hcl
```

The build process will automatically run the Ansible playbook (`ansible/setup.yml`) within a chroot environment, installing KDE Plasma and necessary packages.

## Ansible Standalone

If you already have a baremetal Arch Linux installation or VM, you can run the Ansible playbook directly to install KDE:

```bash
ansible-playbook -K -i "localhost," -c local ansible/setup.yml
```
